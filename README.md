## Featured Project — Online Food Delivery Intelligence

**Pipeline:** `CSV → Python (Pandas) → Data Cleaning → PostgreSQL (Railway) → Power BI`

| Detail | Value |
|---|---|
| Customers analysed | 388 |
| Variables | 13 |
| Database | PostgreSQL (hosted on Railway) |
| BI Platform | Power BI |

**Key questions explored:** who orders food online most, how income relates to ordering behaviour, which demographics show stronger digital adoption, and what patterns emerge across customer characteristics.
