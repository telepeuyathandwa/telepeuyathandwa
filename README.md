# 04. 任務記録 / FEATURED PROJECT

<img src="https://capsule-render.vercel.app/api?type=rect&color=0:00DFD8,100:FF0080&height=3&width=100%" />

## Online Food Delivery Analysis

**An end-to-end data analytics project**

<a href="https://github.com/telepeuyathandwa">
<img src="https://img.shields.io/badge/VIEW%20GITHUB%20PROFILE-181717?style=for-the-badge&logo=github&logoColor=white" />
</a>

### Project overview

Analysed an online food delivery dataset to explore customer behaviour, ordering patterns, demographics and feedback.

### Tools used

- **Python & Pandas** — Data preparation and analysis
- **PostgreSQL** — Relational data storage and SQL querying
- **Power BI** — Interactive dashboard development
- **GitHub Codespaces** — Development environment

### What I worked on

- Prepared and analysed a dataset containing 388 records.
- Explored ordering behaviour and customer characteristics.
- Examined demographic, income, education and feedback patterns.
- Connected analytical work with a PostgreSQL database.
- Developed a four-page Power BI dashboard to communicate findings.

### Key observation

The project reported a 78% reorder rate in the analysed dataset. This is a dataset-specific finding, not a claim about the entire food delivery industry.

**Project goal:** Demonstrate how data preparation, database querying and visualisation can work together to support business analysis.
